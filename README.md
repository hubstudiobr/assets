# Assets — Studio Virtually

Repositório público de assets visuais usados nos HTMLs do `studio-docs`.

## Como usar

Todos os arquivos são acessíveis via URL pública:

```
https://raw.githubusercontent.com/hubstudiobr/assets/main/<caminho-do-arquivo>
```

**Exemplo:**
```
https://raw.githubusercontent.com/hubstudiobr/assets/main/logos/studio-virtually/virtually-logo.svg
```
